Continue the existing **Travel & Land** application.

The authentication, PIN, biometric login, Clerk integration, navigation, and current Home visual design are already implemented.

**Do not rebuild or replace the authentication system.**

Focus only on converting the current Home screen into a properly structured, data-driven MVP dashboard.

## Goal

Build the Home dashboard for the Tourism + Land Sourcing application.

The Home screen should provide users with quick access to tourism discovery, accommodation, maps, bookings, wallet/travel pass, and land sourcing.

* Current location

* Location

* Category
