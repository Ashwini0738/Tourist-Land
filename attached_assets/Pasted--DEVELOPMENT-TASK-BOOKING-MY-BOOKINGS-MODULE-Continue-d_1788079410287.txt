# 18. INVENTORY SAFETY

Prevent overselling.

When a booking is created:

1. Recheck availability.
2. Lock/reserve inventory safely.
3. Create booking.
4. Update inventory consistently.

Use a database transaction where appropriate.

The booking operation should be atomic.

Do not:

Check availability

then separately create booking

without protecting against concurrent bookings.

---

# 19. IDEMPOTENCY

Prevent duplicate bookings caused by:

* Double tapping Confirm
* Network retries
* App retry
* Request duplication

Implement an idempotency mechanism for booking creation where appropriate.

A repeated request should not create two bookings.
