# OBJECTIVE

Build the **Land Sourcing MVP**.

The goal is to allow:

### Traveller/User

* Discover land/property opportunities
* Search properties
* Filter properties
* View property details
* View property location
* Save property to favorites
* Submit an enquiry
* Track enquiry status

### Vendor/Owner/Agent

* Create property listings
* Edit their own listings
* Manage property information
* Receive enquiries
* Respond/update enquiry status

### Admin

* Review property listings
* Approve/reject listings
* View enquiries
* Manage property status
* Monitor sourcing activity

This is a **land sourcing and enquiry platform**, NOT a property transaction platform.

Do NOT implement property purchase/sale transactions yet.

# 29. DUPLICATE ENQUIRIES

Prevent obvious accidental duplicate enquiries.

For example:

Same user + same property + active open enquiry

should warn:

"You already have an active enquiry for this property."

Do not prevent a new enquiry forever.

Allow a new enquiry after the existing one is closed if business rules permit.

# 35. SECURITY

Strictly enforce:

### User

Can:

* View public properties
* Favorite properties
* Create own enquiries
* View own enquiries

Cannot:

* View another user's enquiry
* Change enquiry status
* Access private property documents

### Vendor

Can:

* Manage own properties
* View own property enquiries
* Update permitted enquiry statuses

Cannot:

* Manage another vendor's property
* Approve own property
* Access unrelated enquiries

### Admin

Can:

* Review properties
* Approve/reject
* Manage platform enquiries
* Assign enquiries
* View sensitive operational information

All authorization must be server-side.
