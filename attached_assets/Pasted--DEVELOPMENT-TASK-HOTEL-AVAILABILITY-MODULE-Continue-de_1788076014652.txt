# 3. AVAILABILITY LOGIC

Availability must consider:

* Check-in date
* Check-out date
* Number of adults
* Number of children
* Number of rooms
* Room capacity
* Existing reservations where available
* Room status

Rules:

* Check-out must be after check-in.
* Past dates are invalid.
* Adults must be >= 1.
* Rooms must be >= 1.
* Invalid date/guest combinations must be rejected.

Do not claim availability when there is no underlying inventory.
