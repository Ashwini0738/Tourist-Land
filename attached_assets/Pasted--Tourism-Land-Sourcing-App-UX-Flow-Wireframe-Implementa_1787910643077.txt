# Tourism + Land Sourcing App — UX Flow & Wireframe Implementation

Continue development of the existing project.

Do not recreate the project from scratch.

Create the complete mobile UX structure and low-fidelity wireframe implementation for the MVP.

The application must feel like a modern tourism/travel application while also providing a clearly separated Land Sourcing experience.

## Primary Navigation

Use a mobile bottom navigation structure:

* Home
* Explore
* Bookings
* Land
* Profile

Add access to:

* Notifications
* Favorites
* Wallet

## Authentication Flow

Create:

Splash
→ Login
→ PIN Login
→ Biometric Login
→ Home

First-time user:

Splash
→ Login
→ Mobile/Email verification
→ Create PIN
→ Enable Fingerprint/Face ID
→ Home

Provide fallback PIN authentication when biometrics are unavailable.

## UI Requirements

Create mobile-first wireframes with:

* Clear hierarchy
* Large touch targets
* Consistent spacing
* Accessible typography
* Loading states
* Empty states
* Error states
* Skeleton states
* Confirmation states

Do not focus on visual polish yet.

Focus on correct navigation and user journeys.

Make sure every major screen can be reached without dead-end navigation.

At the end, test every navigation path and fix broken routes.
