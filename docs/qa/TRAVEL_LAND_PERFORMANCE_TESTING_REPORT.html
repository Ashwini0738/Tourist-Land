7. Defects resolved in this QA cycle

  • Prevented competing Stripe checkout sessions during simultaneous requests.
  • Replaced the property enquiry screen’s false success state with real validated API persistence and stable retry behavior.
  • Removed fabricated enquiry receipts when persistence is unavailable.
  • Added user-scoped persistent enquiry idempotency and transactional history creation.
  • Added safe JSON handling for malformed request bodies and unhandled route failures.
  • Fixed unknown property IDs reaching UUID comparisons and returning database errors.
  • Restricted persisted property detail and enquiry flows to published properties.
  • Subtracted active reservations from configured availability and rechecked each booking night under lock.
  • Fixed catalog room IDs being compared to UUID columns.
  • Fixed admin hotel status audit metadata so omitted fields are not recorded as null.
