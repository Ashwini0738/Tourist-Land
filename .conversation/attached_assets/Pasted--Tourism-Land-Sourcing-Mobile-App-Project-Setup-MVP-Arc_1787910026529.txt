# Tourism + Land Sourcing Mobile App — Project Setup & MVP Architecture

Build the foundation of a production-ready cross-platform mobile application for **iOS and Android**, with a mobile-responsive web version.

The application is a combined:

1. Tourism discovery and booking platform
2. Land/property sourcing platform

The application must be designed for future deployment to:

* Google Play Store
* Apple App Store
* Mobile web/PWA

## Technology Requirements

Use:

* React Native
* Expo
* TypeScript
* Expo Router
* Node.js + TypeScript backend
* REST API architecture
* PostgreSQL database
* Drizzle ORM
* Secure authentication/session architecture
* Environment variables for secrets
* Responsive mobile-first UI

Do not hardcode secrets, API keys, database credentials, payment keys, or authentication secrets.

## MVP Roles

Create support for these roles:

### Tourist/User

* Browse destinations
* Search places and hotels
* View destination details
* View hotel/room availability
* Create bookings
* Make payments
* Manage wallet
* Save favorites
* Submit reviews
* Receive notifications
* Browse properties
* Submit property enquiries

### Property Owner/Agent

* Manage property listings
* View enquiries
* Update property information

### Admin

* Manage users
* Manage destinations
* Manage hotels
* Manage rooms
* Manage bookings
* Manage properties
* Manage reviews
* Manage approvals
* Manage offers/events
* View basic platform activity
